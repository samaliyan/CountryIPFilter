Country IP Filter (version 4.0)

This program lets only IPs of the countries you choose connect to chosen ports or programs of this server (for example Revit Server, Remote Desktop or a database).

Use

  1. Double-click the setup file, for example CountryIPFilter-Setup-4.0.4.exe.
  2. Press Yes in the Windows prompt.
  3. Answer Yes to the install question. The program installs itself to C:\Program Files\CountryIPFilter (only Administrators can change that folder), adds shortcuts to the Start menu and the Desktop, and opens. From then on open it from the Start menu.
  4. Under "Countries", choose a country in the list.
  5. Press "Add country". Repeat for every country whose users must connect.
  6. Under "Ports and programs", choose TCP or UDP, then type the port number or choose a service in the list.
  7. Press "Add port".
  8. Press the big "Turn protection on" button.
  9. Read the message and press Yes.
  10. If the banner at the top does not turn green, press the big "Fix problems" button.

The country IP lists are updated automatically every 4 weeks. The program does not need to stay open.

Colour of the banner

Green: protection is on and works.
Orange: there is something worth fixing (or protection is off and a port is open to everyone).
Red: protection does not fully work; press the big button or the button next to each problem.
Grey: protection is off.

Countries

  • You can choose one country or several. Users from all of them can connect.
  • While protection is on, adding or removing a country downloads the lists again at once.
  • The lists come from RIPEstat and cover every country in the world.

Ports and programs

  • Port: choose TCP or UDP, type the number (or choose a service in the list) and press "Add port".
  • Program: press "Add program (exe)…" and choose the program file. The program is then reachable from the chosen countries on every port it uses. Install server programs in C:\Program Files, so other users cannot replace the file.
  • Remove: click the row in the table, then press "Remove selected item".

"Status" column

  • Chosen countries only: correct.
  • Open to everyone: other countries can still connect.
  • Closed to all (even chosen): the users cannot connect either.
  • Closed or Open to a few specific IPs: protection is off and the port is as it was.

Language and version

  • The program has English and Persian. Press the button at the bottom of the window ("فارسی" or "English"). The program closes for a moment and opens again.
  • The version is shown in the window title.

Turning off

"Turn protection off" removes the "these countries only" Rules and turns the old Rules back on. If a port will then be closed for everyone, you are told before.

Notes

  • Users whose VPN gives them an IP of another country cannot connect; they must switch the VPN off.
  • Only IPv4 is let in.
  • The program never switches off, without asking, Rules that might also cut Remote Desktop, SSH or other services.
  • The program's files are in C:\Program Files\CountryIPFilter\data. The other settings are stored inside the Windows Firewall Rules themselves. To update, just run the setup file of the new version.
  • The monthly update is a Windows Scheduled Task that runs only PowerShell and does not need the program file. A new list that is much smaller or much bigger than the last one is not used.
  • Upgrading from "Iran IP Filter" 3.x: the old Rules are moved over automatically; nothing changes for the users. Then delete IranIPFilter.exe.
  • If there is a problem: press "Copy problems" above the list of problems, or "Technical details" and then "Copy text", and send the text to support. In any message box, Ctrl+C copies its text.
  • To remove the program: turn protection off, then remove "Country IP Filter" in Settings, Apps.
